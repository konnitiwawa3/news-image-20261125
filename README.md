The page is drawn with the Python standard library. It uses hand-drawn type, seeded paper grain, and engraved panels. Each article's reporting credit is in `main.py`.

```sh
python3 main.py entry.png
```

The entry point writes a deterministic 1024 × 1024 RGB PNG. Without an output argument, it writes to `/output/entry.png`.
